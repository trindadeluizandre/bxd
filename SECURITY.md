Reportando uma Vulnerabilidade

Se você encontrar qualquer vulnerabilidade de segurança, falha lógica ou exposição de dados neste projeto educacional, por favor, entre em contato diretamente de forma privada através do e-mail do mantenedor ou abra uma discussão privada. Não abra issues públicas para vulnerabilidades sensíveis.
